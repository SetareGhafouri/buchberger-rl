# Results

Everything here is generated by [`../reproduce.sh`](../reproduce.sh).

| File | Contents |
|---|---|
| [`strategies/strategies.md`](strategies/strategies.md) | Seven hand-designed selection strategies on four ideal distributions (1,000 ideals each) |
| [`policy_analysis.json`](policy_analysis.json) | Correlations between the agent's preference scores and interpretable pair features; agreement with heuristics |
| [`figures/training_curve.png`](figures/training_curve.png) | Main training run against heuristic baselines |
| [`figures/ablations.png`](figures/ablations.png) | Training curves of the ablations |
| [`figures/preference_vs_degree.png`](figures/preference_vs_degree.png) | Preference score as a function of a pair's lcm degree, trained vs. untrained |

Per-run outputs live in `../runs/<run>/`:

* `config.yaml`: the exact configuration used;
* `train_log.csv`: per-epoch training statistics (cost, KL, entropy, clip fraction, timing);
* `checkpoints/best.npz`: the checkpoint with the best 10-epoch smoothed training cost;
* `eval_<distribution>[_tag]/summary.md`: paired evaluation tables, plus `per_ideal.csv` with the cost of every method on every held-out ideal.
